# Smart Campus Analytics — Predict, Optimise and Improve Student Success

Angular + TypeScript frontend, Python FastAPI backend (Lambda Function URL via Mangum), DynamoDB single table,
Cognito authentication, CloudFront in front of two IAM-protected Function URLs. Rules-based scoring and risk; no paid AI.

## Run locally

```bash
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements-dev.txt
cd frontend && npm ci && npm run build && cd ..
cd backend && ../.venv/bin/python -m app.seed      # 150 fictional students (labelled synthetic, fixed seed)
../.venv/bin/python local_server.py                # http://127.0.0.1:8000 — local demo sign-in (never enabled in AWS)
```

## Tests

```bash
cd backend && ../.venv/bin/python -m pytest -q     # roles, scoring, imports, concurrency, CloudFront headers, DynamoDB (moto)
cd frontend && npx ng test --watch=false           # interceptor: payload hash + app token
node e2e/journey.mjs                               # seed -> sign in -> dashboard -> enter data -> score -> intervention -> outcome
```

Layout: `backend/` API and Lambda handlers · `frontend/` Angular app · `config/` role matrix, scoring and curriculum ·
`docs/` documentation (`role-matrix.md` is generated by `backend/tools/render_role_matrix.py`) · `e2e/` journey test.
